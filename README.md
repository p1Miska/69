# Прибаль — версия 1.0 (каркас)

Открой `index.html` в браузере — всё работает без сервера и без сборки.
Для GitHub Pages: залей папку в репозиторий → Settings → Pages → Deploy from branch → `main` / root.

## Что положить в папки (сейчас там заглушки — просто замени файлы с теми же именами)

**images/** — `candu sintwo fix delta shprotik allincy nnwen wixon igrobaiter complitplay bibz backfun miska` (карточки, рекомендую 3:4),
`empty box1 box2 box3 potate magaz kazik craft evil` (.png).
Необязательно: `level1.png`, `level2.png` — фоны уровней (пока сплошной цвет; если файл появится, подхватится сам).

**sounds/** — `click.mp3`, `kazik.mp3` (открытие пака), `soundtrack.mp3` (музыка).
Новый: `stairs.mp3` — звук лестницы из Майнкрафта. Пока его нет, шаги синтезируются кодом.

**videos/** — `shpr.mp4` (видео Шпротика: играет, когда его ставят в слот; тап закрывает).

**fonts/** — `minecraft.ttf` (или `minecraft.woff2`). Пока его нет, используется запасной моно-шрифт.
Проверь лицензию шрифта перед публикацией.

## Структура кода

| Файл | За что отвечает |
|---|---|
| `js/config.js` | **вся игровая дата**: карточки, редкости, паки, уровни, валюты, цены, крафт, интро, «Что будет в 2.0» |
| `js/game.js` | правила игры без интерфейса: эффекты, паки, крафт, подъём |
| `js/ui.js` | экраны и окна |
| `js/core.js` | хелперы, сохранения (`Store`), заглушки `Auth` и `Leaderboard`, звук, анимации |
| `css/style.css` | стили (мобильный + ПК-раскладка) |

## Как расширять (2.0)

- **Новая карточка** — запись в `CARDS` + картинка `images/<id>.png`. Эффекты собираются из готовых блоков: `clickMult`, `cardMult`, `income`, `doubleRarity`, `cloneRandom`.
- **Новый пак** — запись в `PACKS` (`level` — с какого уровня, `chances`, `price`).
- **Новый уровень** — раскомментировать/дописать запись в `LEVELS`: убрать `locked`, добавить `color`, `bg`, `enter`.
- **Новая валюта** — запись в `CURRENCIES`. Отобразится в шапке и сохранится сама.
- **Катсцена** — добавь строки в `INTRO` (картинка + текст на каждую).
- **Мини-игры** — отдельный файл `js/minigames.js` + кнопка в `openMenu()` / на уровне 3.
- **Аккаунты и лидерборд** — заменить `Store` (сохранения) и наполнить `Auth` / `Leaderboard` в `core.js`. Игра уже вызывает `Leaderboard.submit(score)` при подъёме на уровень.

## Баланс (черновик, всё меняется в config.js)

Клик = 1 прибаль. Ннвен даёт 0.1 картошки/сек (в старом коде было 1/сек), Complitplay: клик ×4, доход карточек ÷2, Шпротик сгорает при постановке в слот. 69 прибали = 1 картошка (пачки дешевле). Ящики: 3 / 12 / 30 картошки.
Подъём на уровень 2: 1500 прибали + 10 картошки. Продажа дубликата: 1 / 3 / 8 / 20 картошки по редкости.
